## 📖 About The Project

This Angular application provides a rich, interactive user interface for the Travel & Tour Management System. It consumes the Spring Boot REST API to deliver a seamless experience for browsing tours, booking flights, managing itineraries, and administering the platform.

### Key Features

- 🎨 **Modern UI** — Clean, responsive design built with Bootstrap and Angular Material
- 🔐 **Authentication** — Login/Register with JWT token handling via HTTP interceptors
- 🗺️ **Tour Browsing** — Browse, search, filter, and view detailed tour information
- ✈️ **Flight Search & Booking** — Search flights, select schedules, and make bookings
- 📅 **Booking Management** — View, cancel, and manage personal bookings
- 👤 **User Dashboard** — Profile management and booking history
- 🛡️ **Admin Panel** — CRUD operations for tours, flights, users, and bookings
- 📱 **Responsive Design** — Works seamlessly on desktop, tablet, and mobile
